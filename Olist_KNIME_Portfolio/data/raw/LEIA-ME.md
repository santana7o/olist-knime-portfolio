# Dados brutos

Baixe o [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) no Kaggle e copie os CSVs para esta pasta, mantendo os nomes originais (`olist_orders_dataset.csv`, `olist_customers_dataset.csv`, ...).

Os dados são publicados pela Olist sob a licença CC BY-NC-SA 4.0 e não são redistribuídos neste repositório.
